User guide

TETHER Mission Control shows how simulated rescue rovers behave in a disaster, on a real map.

The idea

A rover starts at a base, must find a target and return before its battery runs out. Obstacles block it, hazards drain the battery faster and the base's radio only reaches so far. Each scenario is a grid placed on a real location, and every agent's route is stored as geometry in PostGIS.

Browsing

  1. On the scenarios page, pick a scenario from the list or the map.
  2. Press Play to replay the rover's route, or drag the slider.
  3. Click the map to see the three nearest hazards or obstacles.
  4. Read the results table: success, path length, time spent in hazards, radio coverage and the "point of no return".

Finding scenarios by place

Click the dashboard map to pick a point, set a radius and press Near picked point to list scenarios within that distance.

Signed-in users

  • New scenario: choose a type, a location, a seed and a battery. The same seed always generates the same map.
  • Edit the name and description, Re-run route and Delete on your own scenarios.
